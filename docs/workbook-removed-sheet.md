# Selected removed configuration checkpoint

Source deletion capture now retains the exact selected desired SDK sheet and its
position as `removedSheet`/`removedIndex`. These optional fields are a strict pair
for older protected records: missing both remains readable legacy data, while a
partial pair refuses. The selected ID, finite/bounded snapshot shape, logical
area, position and cell coordinates are checked. Capture also checks the current
native axis identity and unique selected position. Only the selected sheet is
cloned; no opaque extra workbook snapshot is introduced.

The actual source/ACK baseline stays separate. A source-level real SDK fixture
has baseline17, captures desired19, removes it, then native Undo restores19.
Later editing to20 does not alter the retained copy. A pending creation's future
conversion must similarly derive baseline17 from the actual checked target B
and retain its separately captured removed desired19; no provisional B version
or baseline is invented here.

The pair is protected data, not a native issuer or historical-file grant. Actual
prospective admission continues through the entire existing draft encoder and
its byte/quota checks before an SDK callback. The current draft byte cap is
128MiB and is unchanged. Historical access and recovered provenance still need
their separate checks. The existing baseline-only helper remains baseline-only;
the new pair can be attached by the upcoming checked pending-target conversion.
Controls, pending conversion and complete history/recovery remain uninstalled.

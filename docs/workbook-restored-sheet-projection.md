# Restored worksheet projection prototype

This is an uninstalled source/plan checkpoint. Worksheet membership controls
remain off. It does not qualify live source Delete Undo, HTTP history access,
contained worker execution, recovery, retirement or packaged browser behavior.
The existing authorized historical-asset API remains the actual file-access
boundary; serialized markers and receipt associations are data, not grants.

## Owning path

`grid-sheet-projection.ts` selects one retained context matching the present
restored sheet's full descriptor, artifact scope and axis generation. It derives
existing `origin: restore`, `template.versionId/versionSha256` and versioned
`baselineIdentity` fields. Current source survivors keep current data and order.
The restored diff baseline is the selected historical acknowledged SDK sheet,
not its removed desired configuration or another sheet from the old workbook.
The existing worker independently validates frozen historical bytes, full reader
baseline identity and resource continuity before assembly and calculation.

`grid-restored-sheet.ts` merges only the selected referenced normalized style
closure into a clone of the current model. Current style indices stay fixed;
historical indices map to deterministic equal definitions or appended entries.
Default style, date and theme interpretation must agree. The resulting complete
model must pass the existing strict document schema.

Those merged indices are **only diff indices**. `grid-plan.ts` translates authored
restored cell guards back to each exact historical cell's original compact
ordinal. With a structural plan it uses that plan's source-coordinate origins.
The normalized historical definition must equal the diff definition. New or
missing coordinates cannot borrow a style. Intentional formatting still uses
the separate style adapter. The contained writer then applies its existing
independent original/prepared style ownership checks against actual XML.

## Evidence

The genuine initial scratch regression used actual styled B.xlsx, the installed
SDK and existing source writer. Before Delete it changed the survivor to20,
renamed it and set22.25pt; removed desired was19 versus historical baseline12.
After a checked stand-in ACK and actual native Undo, unchanged projection refused
historical restoration. B's compact style1 meant bold11; C's compact style1 meant
Calibri22.25. Treating those ordinals as interchangeable would be wrong.

The corrected plan used original historical guard1 while its synthetic merged
model used index2. The actual source assembler accepted the declared historical
bytes, independently reopened XLSX contained restored19/bold11 and current
survivor20/22.25, and the survivor's current worksheet XML was byte-identical.
Missing template, wrong asset SHA and a forged baseline hash refused. A second
actual ZIP/SDK case included a qualified cross-sheet formula: native rename
rewrote its reference; the restored output referenced `Current survivor` and
calculated21 without reverting the survivor edit. Both scratch probes disposed
SDK kernels normally and started no server or browser.

Scratch evidence is under `/tmp/workbook-restored-projection-proof/` and
`/tmp/workbook-restored-projection-formula-proof/`. These are local source
assembler probes, not container, authorization, crash or receipt-server proof.
The checked receipt in each is a stand-in; the asset bytes themselves are real.

Four committed tests use strict public models extracted from that real ZIP pair
and actual SDK Delete/Undo. They cover exact derived template/baseline identity,
source input preservation, scoped/receipt refusal, inherited row/column style
closure, historical guard translation through structural origins, wrong style
and new-coordinate refusal. The model fixture contains no historical asset or
authorization. Affected checks passed88 cases in9 files, full fork typecheck and
guard. Initial web typecheck exposed a protected JSON-null versus SDK snapshot
type boundary; its explicit narrow adapter retains existing blank-cell semantics.

Live source Delete history must still qualify compound native command payloads,
private issued entry identity, pre-pop durable protection, checked historical
receipt association, pending/lost ACK recovery, worker epochs and retained-root
retirement. This prototype does not enable any of those controls or claim the
complete worksheet feature.

# Projector to historical-asset acceptance handoff

This is a test-only source boundary. It does not install membership controls or
qualify a live Delete/Undo controller, protected journal recovery, receipt-server
authority or container execution. The native contained harness separately owns
same-file authorization, frozen assets and actual network-disabled rendering.

`apps/web/tests/helpers/workbook-restored-projection-handoff.cts` is invoked only
with explicit local input/output paths. Its CommonJS carrier selects one pinned
SDK runtime family. No product accepts a source-checkout path or this protocol.
It initializes the actual SDK with the supplied strict historical preview, edits
removed B2 to19, changes the survivor to20/22.25pt, renames the survivor and runs
native Delete. It captures the source context before Delete and leaves the native
history in memory. It never serializes SDK history or imports recovered metadata
as a live issuer.

The delete phase outputs the existing strict plan. The restore phase repeats
that deterministic chronology and requires its regenerated deletion plan to
equal the declared committed plan exactly. It checks the actual fresh target
preview's authored inputs against the native acknowledged snapshot using the
existing validator. It validates the supplied applied receipt against declared
operation/project/file/source/target identities, associates the pre-save history
version, and binds the full current model and acknowledged snapshot through the
existing continuity helper. Native Undo then restores19 while retaining20; the
existing projector emits its original-ordinal style guard, explicit template
version/SHA and versioned baseline identity. This helper cannot establish that
its receipt came from a server: the native harness must supply the real checked
receipt and authorize every historical asset independently. Current styles and
raw metadata are also checked by its independent output oracle.

without publishing an output plan. The committed fixture consists of public

asset, permission grant or live history proof. Full fork typecheck and guard
passed. The helper's actual native fixture/ZIP dry-run also passed the separate

local formula cache19, renamed qualified reference/cache21, survivor20/nonbold

These local dry-run bytes and logs are under
`/tmp/workbook-projected-assets-dryrun/`. An early oracle command ran before the
writer finished and got ENOENT; the completed writer and final oracle both
succeeded. No server, container, browser or production process was started.

# Free BoardUI date calendar attribution

`date-calendar.tsx` and `date-calendar-shared.tsx` adapt the free BoardUI
Date Calendar and Date Picker month/day primitives from the public registry:
https://www.boardui.com/r/date-calendar.json
https://www.boardui.com/components/date-calendar

The original source comments and design attribution remain in the files.
Adaptations use relative imports for the embedded BoardUI boundary, a 320 px
semantic floating surface, and 32 px previous/next targets. Calendar interaction
and day/month primitives remain the free BoardUI/React Aria implementation.
No Pro full-calendar source is used.
